# Legacy Vanilla JS & Python Prototypes (Archived)

This directory contains the original proof-of-concept vanilla HTML/JS/CSS and Python scripts:
- `app.js` & `style.css` & `index.html`: Pre-v2.0 client-side single-page prototype.
- `server.py` & `process_net_sales.py`: Legacy Python HTTP static server (port 8085) and Pandas calculation scripts.

> **Current Production Architecture**:
> All production reconciliation, knapsack subset-sum matching, live WooCommerce REST sync, Pathao Hermes integration, and AI assistant capabilities are implemented in the modern Next.js 14 + TypeScript architecture under `src/`.
> These files are retained strictly for archival and historical reference.
